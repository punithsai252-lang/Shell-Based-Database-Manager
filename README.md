# ShellForge

ShellForge is a shell-based database manager developed in C.

It provides a simple command-line interface for managing database operations and demonstrates concepts such as C programming, memory management, file handling, and the C toolchain.

## Features

- Command-line shell interface
- Database management operations
- User input handling
- Modular C source code
- Header files for project organization
- Makefile-based compilation
- Executable shellforge program
